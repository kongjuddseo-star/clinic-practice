# 임상실습 배치 관리 (clinic practice)

간호학과 임상실습 배치를 관리하는 웹사이트입니다. 학생 한 명의 3학년 1학기, 3학년 2학기, 4학년 1학기 실습을 한 줄에서 함께 검토하고, 조건에 맞춰 자동으로 배치합니다.

## 학년도와 기수

학생과 학기는 **기수**(어느 해에 3학년인 학생들)에 속합니다. 한 기수는 그해 3학년 1·2학기와 다음 해 4학년 1학기를 거칩니다.

- 화면 위에서 **학년도**와 **3학년/4학년**을 고르면 그 기수만 보입니다.
- 예: 2027학년도 3학년 = 2027년 3학년 기수(3-1, 3-2는 2027년, 4-1은 2028년)
- 예: 2027학년도 4학년 = 2026년 3학년 기수(2026년 3-1, 3-2 이력 + 2027년 4-1)
- 새 기수는 학년도를 고른 뒤 ‘○○년 3학년 기수 만들기’를 누르면 3-1, 3-2, 4-1 학기가 함께 만들어집니다.

## 할 수 있는 일

| 메뉴 | 내용 |
|---|---|
| 학생별 실습 이력 | 학번·이름, 인적사항(참고 포함), 학기별 실습(교과목·기관·병동)을 한 줄에. 같은 기관·같은 병동 재배치는 빨간 테두리, 같은 기관·다른 병동은 주황 테두리. 엑셀로 저장 |
| 자동 배치 | 학기를 골라 배치 실행 → 미리보기(학생별·기관별·점검) → 이 학기 배치로 저장. 엑셀로 저장 |
| 학생 명단 | 엑셀 업로드(같은 학번은 새로 고침), 한 명씩 추가·수정·삭제, 맨 끝 **참고** 칸 |
| 기관·병동 | 과목별 기관 추가·삭제, 정원(1~4기간), 지역 키워드, 성적 우선·여학생만·지역·만학도 우선, 병동 추가·삭제 |
| 학기·이력 가져오기 | 학기 추가·삭제, 기간 입력, 지난 배치표(엑셀)에서 이력 가져오기, 전체 데이터 백업(JSON) |
| 계정 관리 | 계정 추가·삭제, 직위 변경, 비밀번호 초기화 |

## 배치 규칙

반드시 지키는 조건

- 기관·과목·기간별 정원
- 여학생 전용 기관(아인병원, 에이치큐브병원)에 남학생 배정 안 함
- **이전 학기와 같은 기관의 같은 병동에는 배정 안 함**

점수로 우선순위를 정하는 조건 (자동 배치 → 배치 기준 점수에서 조정)

- 성적 우선 기관(강동경희대학교병원, 경희의료원, 이대서울병원, 삼성창원병원): 성적이 높은 학생 우선
- 지역·만학도 우선 기관(안동병원, 안동성소병원 등): 안동·영주 주소지, 35세 이상 만학도 우선
- 그 밖의 기관: 주소지가 가까운 학생 우선
- 이전 학기와 같은 기관(다른 병동)은 감점해서 되도록 피함

자동 배치는 3학년 2학기 구조(성인 4주 연속 + 여성 2주 + 아동 2주)를 따릅니다. 구조가 다른 학기는 ‘학기·이력 가져오기’에서 엑셀로 올려 이력으로 관리합니다.

## Railway 배포

1. Railway에서 **New Project → Deploy from GitHub repo**로 이 저장소를 고릅니다.
2. 서비스의 **Settings → Volumes**에서 Volume을 추가하고 Mount path를 `/data`로 둡니다. 이 Volume이 데이터를 보관합니다. 없으면 다시 배포할 때 데이터가 지워집니다.
3. **Variables**에 아래를 넣습니다.

| 변수 | 값 | 설명 |
|---|---|---|
| `DATA_DIR` | `/data` | 데이터베이스 위치(Volume 경로와 같게) |
| `SECRET_KEY` | 긴 임의 문자열 | 로그인 세션 암호화 |
| `INIT_ACCOUNTS` | `dean\|학부장\|이름;chair\|임상산학학과장\|이름;professor\|임상실습주임교수\|이름;staff\|임상실습행정직원\|이름` | 처음 만들 직위별 계정(아이디\|직위\|이름). 계정이 하나도 없을 때만 사용 |
| `INIT_PASSWORD` | 8자 이상 | 위 계정들의 처음 비밀번호. 처음 로그인하면 각자 바꿔야 함 |

4. **Settings → Networking → Generate Domain**으로 주소를 만듭니다.
5. 각 직위 계정으로 처음 로그인하면 새 비밀번호를 정하는 화면이 나옵니다.
6. 발령으로 사람이 바뀌면 ‘계정 관리’에서 그 직위 계정의 이름을 고치고 비밀번호를 초기화합니다.

시작 명령과 상태 확인 경로는 `railway.json`에 있습니다(`gunicorn`, `/healthz`).

## 처음 쓸 때 순서

1. **학생 명단**: 엑셀 업로드(학번, 이름, 성별, 성적, 연령, 주소, 참고)
2. **학기·이력 가져오기**: 3학년 1학기, 2학기 배치표 엑셀을 각 학기에 올림. 배치이력 검토표의 ‘실습이력 목록’ 시트처럼 학기 열이 있는 파일은 한 번에 나눠 들어감
3. **학생별 실습 이력**에서 확인
4. 다음 학기: **기관·병동**에서 정원·병동을 맞추고 **자동 배치**에서 실행 → 저장

## 로컬 실행

```bash
pip install -r requirements.txt
INIT_PASSWORD=testpass123 python app.py   # http://localhost:5000, 아이디 admin (처음 로그인 때 비밀번호 변경)
```

데이터는 `data/clinic.db`에 저장됩니다(저장소에는 올라가지 않음).

## 구성

- `app.py` — Flask 서버, SQLite, 로그인, API
- `static/engine.js` — 배치 엔진(최소비용 유량)
- `static/app.js` — 화면
- `templates/` — 로그인, 본 화면
